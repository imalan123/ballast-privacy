# Ballast — Privacy Policy

**The published policy lives at
[imalan123.github.io/ballast-privacy](https://imalan123.github.io/ballast-privacy/)** —
that is the URL registered with the App Store, and the one the app links to.

The source is [`index.md`](index.md) in this repository. GitHub Pages renders it from the
`main` branch.

Ballast collects no data. It has no accounts, no servers, no analytics and no third-party
SDKs, and every import in the app is an Apple framework.
